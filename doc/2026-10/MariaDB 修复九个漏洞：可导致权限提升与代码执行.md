#  MariaDB 修复九个漏洞：可导致权限提升与代码执行  
sec随谈
                    sec随谈  sec随谈   2026-10-13 02:06  
  
**摘要**  
MariaDB 于 2026 年 10 月 9 日披露了九个漏洞，涉及其数据库服务器和 Connector/C 客户端库。其中五个漏洞被评为高危，CVSS 评分最高达 8.5。最严重的漏洞可能使经过身份验证的用户提升权限，或在服务器上执行代码。  
  
**为何重要**  
MariaDB 为无数 Web 应用和企业系统提供支持。这些漏洞大多需要已有的数据库账户，但低权限账户或被盗的凭据仍可能成为通往服务器完全控制权的途径。  
  
**攻击原理**  
  
**代码执行与主机接管**  
- CVE-2026-107815  
（CVSS 8.5）：CONNECT 引擎中的栈缓冲区漏洞。经过身份验证的用户可使服务器崩溃，并有可能执行代码。  
  
- CVE-2026-107818  
（CVSS 8.4）：拥有 FILE 权限的用户可在服务下次重启时向其注入环境变量值。  
  
- CVE-2026-107814  
（CVSS 8.4）：RPM 软件包将 mysql 账户的主目录设置在数据目录中，管理员打开登录 shell 时，启动文件可能因此被执行。Debian 软件包不受影响。  
  
- CVE-2026-107821  
（CVSS 8.0）：对 FRM 表文件的验证不严，可能导致内存损坏。  
  
**权限提升**  
有两个漏洞针对 MariaDB 的权限系统。  
CVE-2026-107823  
（CVSS 7.2）允许通过特制的用户名向视图中夹带额外的元数据。同样，  
CVE-2026-107822  
（CVSS 6.4）允许名称冲突的账户借用另一个账户的缓存权限。  
  
**数据泄露与密码窃取**  
CVE-2026-107816  
 和   
CVE-2026-107817  
 可能导致内存泄露或服务器崩溃。与此同时，Connector/C 中的   
CVE-2026-107819  
 跳过了 TLS 主机名检查，因此，中间人攻击者可能截获数据库密码。  
  
**利用情况**  
目前尚未确认这些 MariaDB 漏洞已在真实环境中被利用，同样，也没有确认的公开概念验证（PoC）。  
  
**受影响版本**  
- MariaDB Server 10.6.1 及更高版本，且低于 10.6.28、10.11.19、11.4.13、11.8.9、12.3.3 和 13.0.2。  
  
- MariaDB Connector/C 3.4.1 至 3.4.9。  
  
**补丁与缓解措施**  
- 将 MariaDB Server 升级到 10.6.28、10.11.19、11.4.13、11.8.9、12.3.3 或 13.0.2。  
  
- 将 Connector/C 更新到 3.4.10 版本。  
  
- 将 FILE、CREATE USER 和 GRANT 权限仅限于受信任的管理员。  
  
- 如果不使用 CONNECT 引擎，请将其禁用。
